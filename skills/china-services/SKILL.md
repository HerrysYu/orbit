# 中国本土服务

本 skill 说明服务执行的渠道约束与结果格式。专用手机用不了微信，Mac 微信又会拦截 computer use；若本次没有覆盖目标步骤的已授权服务接口或独立网页，微信小程序、公众号和微信服务需要主人在自己的微信完成。手机只用来操作各服务自己的独立 App。

管家在拆解、选择服务前先用 `china-service-discovery` 实时查本次办理方法；本文件说明执行渠道的技术约束。下列平台是检索示例，不是固定分配、白名单或优先级排名；是否适用以本次目标、地区、官方流程与实际能力为准。

## 路径选择

1. 用户指定渠道时遵循指定；若该渠道无法完成，说明实际限制再提供可行替代，不静默改道。
2. 处理外部服务前，按相关性用 `mcp_list` 和/或 `connectors_list` 检查当前能力与连接状态。优先使用已暴露、权限覆盖目标步骤的服务专用 MCP / 插件；配置齐备不等于连接或鉴权成功。单步 connector 用 `connector_call`，多步在 worker 任务单点名；内置 MCP 通过 `mcp_services` 明确选择。工具缺失、无配置或无权限时停止重复尝试，说明需要的连接 / 授权，不自动安装、改配置或获取凭据。
3. 没有适用的已授权服务接口时，先看公开网页能否完成目标；可用搜索或浏览器完成的步骤就走网页。Playwright 等浏览器 MCP 按需确认当前可用；若服务专用结构接口已覆盖目标，不改走通用浏览器。
4. 只有界面是必要入口、且服务接口和可行网页均不能完成目标时，才用 `computer_use_task`；只有确实仅手机 App / 手机登录态能完成时才用 `phone_task`，在手机上用服务自己的独立 App。派发时写出当次选 UI 的实际原因。
5. 这台专用手机不能用微信，Mac 微信又会拦截 computer use。若没有覆盖本次任务的授权接口或独立网页，告诉主人需要在自己手机的微信里完成，并给具体步骤；不要把该手机或 Mac 微信当作可用渠道。
6. 如果你已经是带有 `orbit_phone` 的手机 worker，就直接使用手机工具，不再派发新的 worker。若执行中发现已授权服务接口或网页入口能更合适地完成任务，结束手机操作并交回 Orbit 调整派单，不要自行改用 Mac。普通执行者没有 `phone_task` 或手机工具时向 Orbit 回报需要手机，由 Orbit 调度。

## 手机 App 路径

1. `phone_begin` 获取锁，`phone_launch` 打开服务自己的 App（名称见文末）。手机上没有该 App 时，`phone_end` 并返回 `blocked`，写明缺少哪个 App，不改走微信；若任务渠道出现更合适的接口线索，先 `phone_end` 并请 Orbit 重新选择，不要自行切设备。
2. 用 App 内搜索或入口输入官方名称，优先选择名称与品牌一致、认证主体明确的官方结果。
3. 打开目标后按任务选择城市、门店、商品、日期或服务。每次只做一个动作，查看动作返回的新截图后再继续。
4. 任务目标已能从当前屏幕回答时结束。当前可见结果不能代表全平台最高分或最低价，应在结果中注明范围。
5. 完成或遇阻时调用 `phone_end`，记录其返回的最终证据路径。设备被占用时返回 `busy` 给 Orbit，用 `watch` 等已有手机 session 完成。

手机坐标、输入、重试和弹窗规则见 `phone-automation`。

## 授权与人工接管

- 仅在任务单明确授权时下单或付款；用户只问价格、门店、库存、余票时，只查询，不下单、不付款。没有付款授权时停在确认页之前，已有订单摘要可按 `needs_approval` 交回。
- 手机的支付、隐私类敏感点击自动执行并记录审计；任务单仍须遵循用户指定的对象、金额、数量与用途。网页和 Mac 操作继续遵循原有审批规则。
- 登录、验证码、扫码、人脸识别、本人密码输入需要主人处理：手机 worker 先 `phone_end`，返回 `needs_human`，写清需要做什么。Orbit 使用 `notify` 和 `ask_user` 提醒，主人处理后继续。
- 位置授权可按任务需要允许；手机号、隐私权限按任务所需范围处理。广告和更新提示关闭，不主动修改账号、通知、支付设置。
- 不向联系人发消息、不加好友、不发朋友圈、不删记录，除非任务单明确授权相应对象和内容。
- 价格、商户、日期或数量与目标冲突时停止并交回，不自行换方案花钱。

## 结构化交付

成功、部分完成和失败都以 JSON 代码块结尾。保留以下业务字段，按实际情况省略不适用项：

```json
{
  "status": "done | partial | blocked | needs_approval | needs_human | cancelled | failed",
  "channel": "phone_app | browser",
  "service": "服务名称",
  "summary": "结果、范围与是否下单",
  "result_type": "order | ticket_options | booking | info | list",
  "items": [],
  "fees": [],
  "total": null,
  "currency": "CNY",
  "merchant": null,
  "times": {},
  "options": [],
  "needs": {"kind": "payment | login | captcha | scan | user_action", "detail": "需要主人做什么"},
  "evidence": "phone_end 返回的绝对路径",
  "screenshots": [],
  "steps_log": []
}
```

金额为数字，没看到的值填 `null` 并说明；可读时间用带时区的 ISO 8601。可附 `component` 和 `props`，对齐 `order_card / ticket_card / booking_card / table`；卡片时间字段必须是 Unix 毫秒，业务状态不能直接使用外层的 `needs_human` 等任务状态。手机截图使用 `phone_end` 路径，浏览器截图用任务目录中的绝对路径。只回传与任务相关的信息，不粘贴页面全文或输入框里的隐私。

## 常用 App 与搜索词

- 外卖、点单：美团、美团外卖、饿了么、瑞幸咖啡、喜茶GO、星巴克、奈雪的茶、蜜雪冰城。
- 出行、票务：滴滴出行、高德地图、铁路12306、携程旅行、同程旅行、航司官方 App、猫眼、淘票票、大麦。
- 挂号、政务：医院全称、各地官方预约挂号平台、国务院客户端、国家政务服务平台、地方政务平台、国家医保服务平台。
- 快递：顺丰速运、中国邮政、EMS、京东、菜鸟。
- 排队、景点：门店或景区全称、美味不用等、官方 App。

名称只是搜索起点；以手机当前显示的认证主体和业务入口为准。中途需要主人时立即结束并交付，不空等，不反复搜索同一入口。
